# Explainable-NIDS 🛡️  

Graph-based network intrusion detection with LLM-generated explanations.

Combines GraphIDS — a self-supervised GNN (E-GraphSAGE + Transformer masked autoencoder, NeurIPS 2025) — with plain-language alert explanations generated by LLMs via the Groq API.

## Dataset
NF-UNSW-NB15-v3 — 2,365,424 labeled NetFlow records, 53 features, 10 attack categories. Download link is in the GraphIDS repo README.

## Roadmap
 [] Phase 0 — Environment setup, dataset loading, LLM proof of concept  
 [] Phase 1 — Dataset exploration and analysis  
 [] Phase 2 — GraphIDS training (E-GraphSAGE + Transformer, benign-only, threshold selection)  
 [] Phase 3 — Graph construction from network flows  
 [] Phase 4 — LLM-generated alert explanations
